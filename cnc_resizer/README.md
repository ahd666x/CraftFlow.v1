# CNC Resizer

این اپ برای پروژهٔ CraftFlow یکپارچه شده است.

- صفحهٔ ابزار: `/cnc/`
- API پردازش: `/cnc/api/process/`
- منطق مستقل و بدون وابستگی به Django: `core.py`
- ابزار و API فقط برای کاربران مدیر/مدیر ارشد قابل دسترسی‌اند.
- فایل‌های CNC آپلودشده در `CncFile` با SHA-256، وضعیت قابل resize و نتیجهٔ اعتبارسنجی ثبت می‌شوند.
- در زنجیرهٔ تولید، محور Y فایل CNC برابر `Part.length` در نظر گرفته شده است؛ تولید خودکار فایل مشتق در فاز بعدی به resolver متصل می‌شود.

برای اجرای نسخهٔ مستقل خارج از پروژهٔ Django:

```bash
python cnc_resizer_standalone.py
```

## گزارش قطعات با ابعاد غیرمعمول

برای شناسایی قطعاتی که طول آن‌ها بیش از ۳۰۰۰ میلی‌متر است، نسبت طول به عرض آن‌ها حداقل ۸ است، یا روی هیچ‌یک از ورق‌های کامل فعال موجود جا نمی‌شوند، دستور زیر را اجرا کنید:

```bash
python manage.py report_unusual_cnc_parts
```

فقط برای یک یا چند سفارش:

```bash
python manage.py report_unusual_cnc_parts --order-id 123 --order-id 124
```

خروجی JSON یا CSV برای بررسی و بایگانی:

```bash
python manage.py report_unusual_cnc_parts --format json > unusual-parts.json
python manage.py report_unusual_cnc_parts --format csv > unusual-parts.csv
```

حدها قابل تغییر هستند:

```bash
python manage.py report_unusual_cnc_parts --max-length 2500 --max-aspect-ratio 6
```

این گزارش هیچ قطعه یا تسکی را حذف و تغییر نمی‌دهد. در حالت «تفکیک CNC» نیز پیش از ساخت G-code، موارد غیرمعمول به‌صورت هشدار در پنل برنامه‌ریزی نمایش داده می‌شوند.

## تفکیک CNC و G-code کامل هر ورق

در صفحهٔ برنامه‌ریزی برش گزینهٔ «تفکیک CNC» را انتخاب کنید:

- قطعاتی که اولین مسیرشان `cnc` است (`routing_code` مثل `cnc.paint`) از فایل `.CUT` خارج می‌شوند.
- همهٔ این قطعات (از چند سفارش) با متریال یکسان روی ورق‌های کامل چیده می‌شوند و برای **هر ورق یک فایل G-code کامل** ساخته می‌شود (`/cnc/sheets/`).
- هدر ابزار و پارک ماشین (`G53`) فقط یک‌بار در فایل می‌آید؛ هر قطعه با یادداشت `; PART ...` جدا شده است.
- قطعهٔ چرخیده‌شده (۹۰°) با حفظ جهت قوس‌ها (G2/G3) تبدیل می‌شود. ابعاد قطعه از مسیر برش (G1/G2/G3) و قوس‌ها محاسبه می‌شود، نه از حرکت‌های سریع.
- ورق‌های برنامه‌ریزی‌شده برای CNC در برنامهٔ `.CUT` رزرو‌شده حساب می‌شوند و قطعه‌ای دوبار چیده نمی‌شود. با «لغو و آزادسازی» ورق و قطعات آزاد می‌شوند.

منطق ترکیب G-code در `gcode_sheet.py` است و بدون Django قابل تست است:

```bash
python -m unittest cnc_resizer.test_gcode_sheet
```

## پست‌پروسسور کنترلر و خروجی دستگاه در ابزار تغییر طول

پست‌پروسسور دیالکت-قفل (`minimal_xy_router`) در `controller.py` ثبت شده است؛ با دو
تنظیم زیر در `selvi/.env`، صفحهٔ `/cnc/` به‌جای «فقط پیش‌نمایش»، G-code آمادهٔ دستگاه
می‌سازد و دکمهٔ «دانلود G-code کنترلر» فعال می‌شود:

```env
CNC_RESIZER_IMPLICIT_UNITS=mm
CNC_RESIZER_SHEET_ADAPTER=minimal_xy_router
```

برای ثبت پروفایل کنترلر در ادمین (تأیید نهایی دستی است): `python manage.py register_cnc_controller`.
اگر فایل از دیالکت کنترلر خارج باشد، خروجی مسدود و علت دقیق در کارت «پست‌پروسسور کنترلر» نمایش داده می‌شود.

## فایل‌های غیرمستطیلی و حالت فقط‌نمایش

فایل‌هایی که لبهٔ صاف بلند موازی محور Y ندارند، مانند قطعات مخروطی یا دارای لبهٔ مایل، در ابزار CNC به‌صورت **فقط‌نمایش** باز می‌شوند. مسیرها و سوراخ‌ها قابل مشاهده‌اند، اما تغییر طول، ثبت الگوی resize و دانلود فایل مشتق برای آن‌ها غیرفعال است و متن فایل هرگز تغییر نمی‌کند.

این فایل‌ها در آرشیو با برچسب «فقط نمایش» دیده می‌شوند و اگر طول قطعه با فایل پایه برابر باشد، برای چیدمان روی ورق CNC قابل استفاده‌اند. تولید فایل مشتق برای تغییر طول چنین قطعاتی عمداً با خطا متوقف می‌شود تا مسیر دستگاه بدون تأیید اپراتور تغییر نکند.
