# قرارداد پروفایل عمومی تغییر اندازهٔ CNC

این نسخه منطق تغییر اندازه را از یک فایل یا ابزار خاص جدا می‌کند. شمارهٔ ابزار (`T2`، `T3`، `T5` و غیره) فقط metadata است؛ نوع عملیات از هندسه و تأیید اپراتور تعیین می‌شود.

## ساختار پروفایل

```json
{
  "axis": "length",
  "reference_points": {
    "start": 0,
    "end": 1084.916,
    "operator": {"x": 0, "y": 0}
  },
  "features": {
    "feature-1": {"mode": "fixed"},
    "feature-2": {"mode": "stretch_straight"},
    "feature-3": {"mode": "repeat_at_pitch", "pitch": 14},
    "feature-4": {"mode": "hole_group", "group": "A"}
  },
  "hole_groups": [
    {"id": "A", "feature_ids": ["feature-4"], "reference": "operator"},
    {"id": "B", "feature_ids": ["feature-5"], "reference": "operator"}
  ],
  "group_distances": [
    {"from": "A", "to": "B", "value": 791, "basis": "operator_reference"}
  ]
}
```

## قواعد ایمنی

محور تغییر برای CNC برابر `length` است و طول روی `Y` قرار دارد. مختصات G-code خط مرکزی ابزار هستند. مقدارهای `Z`، Feed، Spindle، شمارهٔ ابزار و ترتیب عملیات تغییر نمی‌کنند.

قوس‌ها و منحنی‌ها نباید scale شوند. شعاع و شیب باید ثابت بماند و فقط در صورت تعریف صریح، یک بلوک کامل به‌صورت rigid جابه‌جا شود. سوراخ‌ها به‌صورت گروه مدیریت می‌شوند و فاصلهٔ گروه‌ها می‌تواند بر اساس مرکز هندسی یا مختصات مرجع ثبت‌شده توسط اپراتور باشد.

شیارهای طولی می‌توانند با طول قطعه کشیده شوند. رسترهای عرضی با pitch ثابت، مانند فاصلهٔ ۱۴ میلی‌متر، باید در ناحیهٔ مرجع تکرار شوند و خطوط جدید اضافه کنند.

## چرخهٔ اپراتور

ابتدا از مسیر `api/analyze/` موجودی featureها ساخته می‌شود. تا وقتی هر feature دارای قانون `fixed`، `translate`، `stretch_straight`، `repeat_at_pitch` یا قانون معتبر دیگری نباشد، پاسخ `resizable=false` و متن اصلی بدون تغییر برگردانده می‌شود. این حالت برای نمایش هندسه فعال است اما دانلود خروجی را نباید فعال کند.

حالت legacy فعلی همچنان در دسترس است. برای اجرای آن، درخواست مانند قبل با `mode`، `delta`، `enabled` و `manual` ارسال می‌شود و نباید `profile` ارسال شود. پروفایل جدید فقط بعد از تأیید کامل featureها وارد مسیر تولید می‌شود.
